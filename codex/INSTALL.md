# Задание для Codex: установить Telegram-бота

Ты — Codex CLI на Linux-сервере или компьютере человека. Сделай так, чтобы человек мог писать тебе в Telegram, когда он не у компьютера. Работать будет небольшой скрипт-посредник `codex/telegram_codex.py` из этого набора: он получает сообщения из Telegram, передаёт каждое в `codex exec` (продолжая один разговор до команды `/new`) и отправляет ответ обратно.

Человек, скорее всего, не программист. Говори с ним просто, без терминов. Каждый шаг проверяй на деле: запусти и посмотри вывод. Не говори «готово», пока не пройдена проверка из шага 7.

## Что умеет бот (для тебя и для человека)

- Текст, фото и альбомы фото, файлы до 20 МБ, голосовые (если поставить расшифровку, шаг 6), пересланные посты с пометкой, откуда они.
- Присылает файлы в ответ.
- Команды в меню: `/new` — новый разговор, `/now` — что бот делает, `/stop` — остановить, `/usage` — лимиты ChatGPT, `/today` — итоги дня. `/now`, `/stop`, `/usage` срабатывают сразу, даже когда Codex занят.
- Архив переписки по дням и файлы дел: после `/new` бот помнит важное.
- Чего не умеет, в отличие от варианта с Claude: не пишет первым и не показывает ход работы. Пока Codex работает, в чате «печатает…», потом приходит итог. Codex работает в песочнице: менять файлы может только в своей рабочей папке.

## Когда нужен пароль администратора

У тебя нет прав root, и обходить это не надо. Если команде нужен `sudo`, не запускай её сам. Дай человеку готовую строку и объясни так:

> Нужна одна команда с правами администратора. Откройте терминал на этом сервере, вставьте строку ниже и нажмите Enter. Попросит пароль — введите пароль от этого компьютера или сервера. Символы при вводе не видны, это нормально. Когда закончится, напишите мне «готово».

## Шаг 0. Спросить у человека

1. **Создать бота.** Объясни так: «Откройте в Telegram @BotFather, отправьте `/newbot`, придумайте имя и адрес бота (адрес должен кончаться на `bot`). BotFather пришлёт токен — длинную строку вида `123456789:AA…`. Это пароль от бота: сохраните его, но мне в чат не присылайте. Чуть позже вы сами вставите его в терминал». Если у человека уже есть бот для Claude, нужен **другой** бот: один бот может работать только с одной программой.
2. **Часовой пояс** для времени в архиве. По умолчанию Москва.
3. **Рабочая папка.** Объясни: «Бот работает в своей папке: там его правила, заметки по делам и архив переписки. Можно завести для него отдельную папку `~/codex-agent` (советую для начала) или поселить его в папку, где у вас уже лежат проекты, — тогда он будет сразу работать с ними». Если папки с проектами нет, не спрашивай, бери `~/codex-agent`.

## Шаг 1. Проверить, что есть

```bash
cat /etc/os-release | head -2; id -u
command -v systemctl git python3 codex; python3 --version
codex login status
python3 -c 'import markdown_it; print("markdown-it есть")'
loginctl show-user "$USER" -p Linger
```

- Нет `systemctl` — служба systemd не подойдёт. Скажи, что этот набор пока только для Linux с systemd.
- Python ниже 3.10 — нужен более новый.
- Нет `git` — строка с sudo: `sudo apt-get install -y git`.
- `codex login status` не показывает вход — попроси человека выполнить `codex login --device-auth`: появится ссылка и код, их открывают в браузере на любом устройстве.
- Нет `markdown_it` — бот будет работать, но ответы придут без жирного шрифта, списков и блоков кода. Для красивых ответов дай строку `sudo apt-get install -y python3-markdown-it`.
- `Linger=no` — служба не будет работать, пока человек не подключён к серверу. Дай строку `sudo loginctl enable-linger <имя пользователя>`.

## Шаг 2. Набор

```bash
[ -d ~/.local/share/telegram-agent/.git ] && git -C ~/.local/share/telegram-agent pull \
  || git clone https://github.com/gregorythejam/claude-telegram-agent ~/.local/share/telegram-agent
mkdir -p ~/.config/tg-codex && chmod 700 ~/.config/tg-codex
command -v codex > ~/.config/tg-codex/codex-path
```

Если `codex` — это скрипт для Node.js (`head -1 "$(command -v codex)"` показывает `node`), служба должна найти и `node`. Запомни папку из `dirname "$(command -v node)"`, она понадобится в шаге 4.

## Шаг 3. Рабочая папка

По умолчанию `W=~/codex-agent`. Если человек выбрал папку с проектами, `W` — она (полный путь).
```bash
W=~/codex-agent
mkdir -p "$W/дела" "$W/архив-переписки"
[ -e "$W/AGENTS.md" ] || cp ~/.local/share/telegram-agent/codex/AGENTS.md "$W/AGENTS.md"
```
Если в папке уже был свой `AGENTS.md`, не затирай его: допиши в конец содержимое `codex/AGENTS.md` (без первой строки-заголовка) под заголовком `## Telegram` и начни раздел строкой «Правила этого раздела — только для сообщений из Telegram. В обычной работе в терминале они не действуют». Покажи человеку, что добавил.

## Шаг 4. Служба

```bash
mkdir -p ~/.config/systemd/user
cp ~/.local/share/telegram-agent/codex/tg-codex.service ~/.config/systemd/user/
```
Поправь в `~/.config/systemd/user/tg-codex.service`, если нужно:
- рабочую папку, если она не `~/codex-agent`: `sed -i "s#%h/codex-agent#ПОЛНЫЙ_ПУТЬ_К_ПАПКЕ#" ~/.config/systemd/user/tg-codex.service` (переменная `W` между командами не сохраняется, путь подставь сам);
- часовой пояс в строке `TZ=`;
- папку `node` из шага 2: допиши её в начало строки `PATH=` через двоеточие.

```bash
systemctl --user daemon-reload
systemctl --user enable tg-codex
```
Служба пока не запустится: ей нужен токен. Это нормально.

## Шаг 5. Подключить бота: человек делает сам в терминале

Токен человек вводит сам, чтобы он не попал в переписку. Объясни так и дай строку целиком в отдельном блоке:

> Осталось подключить бота. Откройте второй терминал на этом сервере, под тем же пользователем: в VS Code — меню **Terminal → New Terminal**; если вы подключались из Терминала на Mac или PowerShell на Windows — откройте ещё одно окно и подключитесь так же, как в первый раз (`ssh …`). Вставьте строку ниже и нажмите Enter, дальше следуйте подсказкам: вставить токен (символы не видны, это нормально), написать боту «привет» в Telegram и подтвердить, что это вы. В конце бот напишет вам «✅ Готово». Потом напишите мне «готово».

```bash
python3 ~/.local/share/telegram-agent/codex/telegram_codex.py setup
```

Проверь, что служба запустилась: `systemctl --user status tg-codex --no-pager | head -5` и `journalctl --user -u tg-codex -n 20 --no-pager`. В журнале должно быть «Telegram Codex запущен».

## Шаг 6. Голосовые (по желанию)

Если команда `tg-voice` уже есть (`command -v tg-voice`, например её поставили для бота с Claude), ничего делать не нужно. Иначе спроси, нужны ли голосовые. Расшифровка идёт на самом сервере, без внешних сервисов. Модели `small` нужно около 1 ГБ памяти, модели `large-v3-turbo` — около 2 ГБ, у неё лучше качество для русского. Модель выбирай по `free -h`.

Нужен модуль venv: если `python3 -m venv /tmp/x` падает, дай строку `sudo apt-get install -y python3-venv`.
```bash
python3 -m venv ~/.local/share/tg-voice && ~/.local/share/tg-voice/bin/pip install faster-whisper
cat > ~/.local/share/tg-voice/transcribe.py <<'PY'
"""tg-voice <файл> -> текст"""
import os, sys
from faster_whisper import WhisperModel
model = WhisperModel(os.environ.get("TG_VOICE_MODEL", "small"), device="cpu", compute_type="int8", cpu_threads=os.cpu_count())
segments, _ = model.transcribe(sys.argv[1], language="ru", vad_filter=True)
print(" ".join(s.text.strip() for s in segments))
PY
mkdir -p ~/.local/bin
printf '#!/bin/sh\nexec %s/.local/share/tg-voice/bin/python %s/.local/share/tg-voice/transcribe.py "$@"\n' "$HOME" "$HOME" > ~/.local/bin/tg-voice
chmod +x ~/.local/bin/tg-voice
```
Для большой модели добавь в обёртку `export TG_VOICE_MODEL=large-v3-turbo`. Первый запуск скачает модель. Перезапуск бота не нужен.

## Шаг 7. Проверка с телефона (обязательно)

Попроси человека сделать по очереди и после каждого пункта сверь результат:

1. Написать «привет». Бот отвечает.
2. Прислать фото с вопросом. Бот отвечает по фото.
3. Прислать два фото одним сообщением (альбомом) с вопросом. Приходит один ответ про оба фото.
4. Прислать файл (например, PDF или текст) и спросить, что в нём.
5. Переслать пост из любого канала. Бот знает, откуда пост.
6. Голосовое, если ставили. Сначала приходит «🎙 расшифровка», потом ответ.
7. Попросить «сделай текстовый файл с … и пришли мне». Файл приходит в чат.
8. Попросить что-то долгое («найди в этой папке все файлы и посчитай их, а потом подожди минуту») и, пока бот работает, нажать `/now`: приходит «🟢 Работаю». Затем `/stop`: приходит «⏹ Остановил».
9. Нажать `/usage`: приходит расход лимитов ChatGPT.
10. Нажать `/new`: приходит «✅ Новый диалог начат». Спросить про тему из пункта 2, не объясняя: бот находит её в архиве.
11. Нажать `/today`: бот присылает итоги дня.
12. Проверить, что в рабочей папке в `архив-переписки/` есть файл за сегодня с этой перепиской.

Если что-то не работает, смотри журнал `journalctl --user -u tg-codex -n 50 --no-pager`, исправь и повтори пункт.

## Шаг 8. Рассказать человеку, как пользоваться

Коротко и простыми словами:
- Пишите боту как человеку: текст, фото, файлы, голосовые, пересланные посты.
- Начинаете **новую тему** — нажмите `/new`. Бот начнёт с чистого листа и будет отвечать быстрее, а лимиты будут тратиться медленнее. Всё важное он записывает в файлы и найдёт, если вернуться к старой теме.
- Пока бот работает, в чате видно «печатает…». Узнать, чем он занят, — `/now`, остановить — `/stop`, лимиты — `/usage`, итоги дня — `/today`.
- Сообщения, отправленные во время работы, бот возьмёт по очереди после текущей задачи.

## Обслуживание

| Что | Команда |
| --- | --- |
| Состояние | `systemctl --user status tg-codex` |
| Журнал | `journalctl --user -u tg-codex -n 50 --no-pager` |
| Перезапуск (разговор сохранится) | `systemctl --user restart tg-codex` |
| Выключить | `systemctl --user disable --now tg-codex` |
| Сменить бота или владельца | `python3 ~/.local/share/telegram-agent/codex/telegram_codex.py setup` |
| Обновить набор | `git -C ~/.local/share/telegram-agent pull`, затем перезапуск |

**Если бот молчит:**
1. Служба запущена? `systemctl --user status tg-codex`.
2. В журнале «Проверьте токен…» — токен неверный или бота опрашивает другая программа (например, этот же бот подключён к Claude). Нужен отдельный бот: заново шаг 5.
3. Ответ «Codex не завершил ответ» — проверь `codex login status` и лимиты ChatGPT.

**Чего не делать:** не выводить токен в чат и логи; не запускать вторую копию бота; не подключать один бот одновременно к Claude и к Codex.
