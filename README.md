# Claude Code в Telegram

Личный Telegram-бот, за которым стоит настоящий Claude Code на вашем сервере. Вы пишете с телефона, а он работает с файлами, запускает команды, ищет в интернете и присылает результат. Пока работает, сообщает, что делает. Может написать первым, когда закончит долгую задачу.

Набор основан на официальном Telegram-плагине Anthropic и добавляет к нему:

- **/new** — новый разговор с чистого листа: бот отвечает быстрее, лимиты подписки тратятся медленнее;
- **архив переписки** по дням и **файлы дел**: после /new бот помнит важное и находит старые темы сам;
- **пересылки**: бот видит, откуда переслан пост; опросы, истории и новые типы сообщений не теряются;
- **фото без сжатия**, когда важно качество;
- **голосовые** расшифровываются на самом сервере (по желанию);
- **команды в меню бота**: что делаешь сейчас, стоп, расход лимитов, итоги дня;
- **ночная уборка**: напоминание про /new, когда разговор разросся, и (по желанию) ревизия дел.

## Что нужно

- Подписка Claude (Pro или Max) и Claude Code.
- Linux-сервер или компьютер с systemd (например, Ubuntu). Mac и Windows — позже.
- Telegram.

## Как поставить

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, придумайте имя и адрес бота. Сохраните токен, который он пришлёт: это пароль от бота.
2. На сервере запустите Claude Code (`claude`).
3. Вставьте ему одну строку:

   > Установи мне Telegram-агента по инструкции https://github.com/gregorythejam/claude-telegram-agent/blob/main/INSTALL.md

Дальше Claude всё сделает сам: спросит токен, поставит, проверит. Если понадобится пароль администратора, он даст готовую команду и объяснит, куда её вставить.

## Как пользоваться

- Пишите боту как человеку: текст, фото, файлы, голосовые, пересланные посты.
- Бот отвечает только вам. Других людей можно пустить отдельно.

## Команды

| Команда | Что делает |
| --- | --- |
| `/new` | Новый разговор с чистого листа. Нажимайте, когда начинаете новую тему: бот отвечает быстрее, лимиты тратятся медленнее. Важное он помнит по файлам дел и архиву. |
| `/now` | Что бот делает прямо сейчас: работает или свободен, над чем, последние шаги. |
| `/stop` | Остановить текущую работу. |
| `/usage` | Сколько лимитов подписки Claude потрачено за 5 часов и за неделю. |
| `/today` | Итоги дня: что сделано, что не закончено, что ждёт вашего решения. |

`/new`, `/now`, `/stop` и `/usage` выполняет сам мост Telegram, поэтому они срабатывают, даже когда бот занят долгой задачей.

Ещё можно написать «перезапустись»: бот перезапустится и продолжит тот же разговор, придёт «✅ Перезапустился». Помогает, если он завис.

## Безопасность

- Всё работает под обычным пользователем, без прав администратора.
- Бот не открывает портов наружу: он сам ходит к Telegram.
- У агента полный доступ к файлам вашего пользователя на сервере. Ставьте его туда, где вы готовы ему это доверить.
